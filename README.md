# Claude Verlain — Portfolio website

A responsive personal portfolio starter for academic applications, research opportunities, and data science roles.

## Preview locally

1. Download and extract the project folder.
2. Open `index.html` in your browser.

For a better local development workflow, open the folder in VS Code and use the Live Server extension.

## First edits to make

1. Replace the example GitHub links in `index.html` with your actual repositories.
2. Add your real LinkedIn profile URL.
3. Add a CV PDF in this folder and link it from the page (recommended filename: `Claude_Verlain_CV.pdf`).
4. Replace the sample machine-learning and EDA project cards with real projects before publishing.
5. Review the skills list and keep only tools and methods you can confidently demonstrate.
6. Consider adding a project page or notebook link for your Master's research.

## Publish with GitHub Pages

1. Create a new public repository on GitHub, for example `verlain-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the published URL shown in the Pages section.

## Notes

- The site uses Google Fonts, so typography may fall back to system fonts if Google Fonts is unavailable.
- All project illustrations are made with CSS/SVG; no image assets are required.
- This starter intentionally labels two project cards as ideas to replace, not completed work.
