# Claude Verlain — Portfolio

Responsive portfolio website for academic research and data-focused opportunities.

## Files
- `index.html`: content and metadata
- `styles.css`: visual styling and responsive layout
- `script.js`: mobile navigation

## Publish with GitHub Pages
1. Upload or replace these files in the root of `ClaudeVerlain/verlain-portfolio`.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch `main` and folder `/(root)`, then click **Save**.
5. Once deployment completes, check `https://claudeverlain.github.io/verlain-portfolio/`.

## Before publishing
- Confirm the email address `verlain.njoume@aims-cameroon.org` is the one you want public.
- Add links to project repositories or reports only if those resources are ready to be public.
- The project cards intentionally do not contain invented repository links.
